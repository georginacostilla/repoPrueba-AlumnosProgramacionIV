```bash
├── routes/

├── main.jsx
├── index.css
└── App.css
```

## Cómo empezar

1. Clonar el repositorio
2. Instalar dependencias:

```bash
npm install
```

3. Ejecutar la aplicación en modo desarrollo:

```bash
npm run dev
```

4. Abrir la aplicación en el navegador en la URL que indique Vite.
